# Portfolio Website using MERN

A full-stack **personal portfolio website** built using the **MERN stack** (learning MERN).

The project combines a modern frontend with a Node.js backend to create a dynamic portfolio where personal information, projects, skills, and other content can be managed through the application.

## ✨ Features

* 👤 Personal profile and introduction
* 🛠️ Skills and technologies
* 💼 Projects showcase
* 📄 Portfolio content management
* 🔌 REST API integration
* 🗄️ MongoDB database
* 📱 Responsive user interface

## 🛠️ Tech Stack

### Frontend

* React
* JavaScript
* CSS

### Backend

* Node.js
* Express.js
* MongoDB
* Mongoose

## 🚀 Getting Started

Clone the repository:

```bash
git clone https://github.com/maharshi25/portfoliousingmern.git
cd portfoliousingmern
```

Install dependencies for the frontend and backend according to their respective directories.

```bash
npm install
```

Create the required `.env` file for the backend configuration, including your MongoDB connection details.

Start the development server:

```bash
npm run dev
```

> The exact commands may vary depending on the frontend/backend directory configuration.

## 📁 Project Structure

```text
portfoliousingmern/
├── frontend/
├── backend/

```

The frontend handles the portfolio interface, while the backend provides the API and database functionality.
